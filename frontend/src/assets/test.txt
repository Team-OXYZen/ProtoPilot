App idea 1
An IT ticketing system that can generate incidents, change requests, work orders and assign tickets to support agents. The tickets should have fields like title, description, priority, severity, assignee, status, activity notes, etc. The app should be a simple web-app with basic authentication using JWT.

App idea 2
A move rating app for personal use that fetches movies from TMDB external API, uses local storage to save favourites and ratings out of 5 stars. We can search movie name or filter by genre, that's it. You can assume other info as per best of your understanding.

App idea 3
A simple calculator with basic add, subtract, mul, divide operations only. Should look like a real calculator. Should apply BODMAS correctly, divide by zero gives error. No backend calls.

App idea 4
A simple local tic tac toe app with amazing UI, vibrant colors, interactive animations. It will be user vs AI with three level of difficulty. User should be able to reset the game. We should show a pop up after a game ends with a confetti or sad animation.
